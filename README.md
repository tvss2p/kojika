# たって、こじか

うまれたての子鹿を、4本の足を操作して立たせる 3D ブラウザゲーム。

## あそびかた

- キー（またはボタン）を押すたびに、その足がぐっとのびる。ほうっておくと体の重さで曲がる
- かたむいたら、低いほうの足を多めに連打してささえる。連打しすぎた足はつかれて、がくっとなる
- ぐらつかずに3秒立てたら成功。タイムところんだ回数がランキング（この端末に保存）に残る

| | うしろ足 | まえ足 |
|---|---|---|
| 左（奥） | E | I |
| 右（手前） | D | K |

左右は子鹿から見た向きです（子鹿は画面の右を向いているので、手前に見えるのが右足）。スマホでは画面の左下・右下のボタンを指で連打します。押すとよい足のボタンは光ります。

コツ：4本を同じテンポで連打しつつ、かたむいた側（低いほう）を少し多めに押すと立ちやすい。でたらめに連打すると転ぶ。
